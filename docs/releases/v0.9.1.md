# RLR v0.9.1

RLR v0.9.1 is a patch release following the 2026-08-16 real-data full-cycle acceptance.

## Fixes

- L8.5 provider output now enforces the closed verdict set `supports`, `contradicts`, or `unresolved`.
- L8.5 provider evidence identifiers are bound to the located evidence IDs of the same cited paper.
- L10c/L0 round-manifest construction now registers workspace-relative L7 outputs from the authoritative Turing workspace and verifies their hashes.
- Runtime and report version metadata now use the single `0.9.1` release source.

## Acceptance boundary

This release records software and provenance repairs; it does not claim that the scientific hypotheses were validated. The accepted real-data run remained conservative:

- candidate status: `REVISE`
- L7 evidence: `WEAK`
- active hypotheses: `INSUFFICIENT_EVIDENCE`

No causal, adaptive, or functional biological conclusion is asserted by this release.
