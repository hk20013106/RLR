## 二、假说池数据模型（当前实现）

### 存储

SQLite append-only 数据库。所有变更以 event 追加，有 trigger 阻止 UPDATE/DELETE。

### 核心层级

```
families (假说族: 同一语句文本的集合)
  └── versions (假说版本: 不可变定义，含 operationalization + falsification_criteria)
        └── occurrences (候选×轮次 的具体实例)
```

### 两套状态投影

**Workflow（per occurrence）**：
```
PROPOSED → SELECTED → METHOD_DESIGNED → METHOD_APPROVED → EXECUTED → AUDITED → REVIEWED → RETAINED
   ↓           ↓            ↓
REJECTED   ARCHIVED    REJECTED → REVISION_REQUIRED → SUPERSEDED
```

**Epistemic（per hypothesis version，L9a 独家写入）**：
```
UNASSESSED → INSUFFICIENT_EVIDENCE / PROVISIONALLY_SUPPORTED / CONTRADICTED / FALSIFIED
```

### 方法存储

方法不是独立表，是 L4 delta 的一部分（strategies 数组，含 strategy_id, hypothesis_ids, steps）。L6 通过 analysis_plan 关联具体脚本。L7 执行结果记录在 evidence_records 表（source_kind=L7_RESULT）。

### 跨轮次

loop-memory JSON 传递：terminal_decision, required_new_search_directions, unexplored_branches, evidence_kept/dropped。下一轮 L10b 通过 next_round_proposal 创建新 hypothesis_id（DERIVED/REVISION_OF）。

### 关键约束

- 所有 reject/falsify/archive 都是事件记录，**永远不删除历史**
- Epistemic 状态是离散的 5 个值，不是连续概率
- Ranking 用 ELO 分数（advisory），不改变正式 gate 或 decision
- 没有贝叶斯后验分布计算

## 四、可视化方案

### 现状判断

**市面上没有开箱即用的系统能直接可视化 research loop 的假说池演化。** 现有工具要么只做存储（ideas/experiments），要么只做通用知识图谱。需要拼装。

### 推荐架构：三层

```
Obsidian (人类可读存储 + 编辑入口)
   ↓
SQLite ledger (已有，append-only event log)
   ↓
Streamlit + Plotly dashboard (交互式可视化)
```

**核心原则：LLM 负责产生/评估假说，可视化交给确定性脚本。** 不用 agent 做可视化。

### Obsidian 原生插件（零代码，快速但有限）

| 插件 | 能力 | 局限 |
|---|---|---|
| SQLite DB Viewer | 直接在 Obsidian 里写 SQL 查询 + 生成图表 | 手动查询，无自动化 |
| Dataview | 基于 frontmatter 的表格/列表 | 不支持跨轮状态转移 |
| Excalibrain | 图谱视图 | 不适合版本 lineage |

**结论：Obsidian 插件适合快速查看，不适合科研级演化追踪。**

### Streamlit + Plotly 方案（推荐，10 行 Python 起步）

```bash
pip install streamlit pandas plotly
```

核心脚本只需读 SQLite → DataFrame → 图表。**不需要写 JSONL 中间层**，直接从已有 SQLite 读取。

### 5 个核心视图

| 视图 | 内容 | 实现 |
|---|---|---|
| 1. 假说池总览 | 所有假说按 epistemic/workflow 状态分组 | stacked bar / treemap / table |
| 2. 跨轮次状态转移 | Round 1→2→3 的状态变化流 | Sankey / alluvial diagram |
| 3. 单假说演化 lineage | 版本树：v1→v2→v3 + 每步触发事件 | tree / timeline |
| 4. 假说—实验—证据图 | Hypothesis/Experiment/Evidence 三类节点 + supports/contradicts/refines 边 | Cytoscape.js / pyvis |
| 5. 单假说证据时间线 | 横轴 round，纵向列出每次事件（proposed/tested/supported/contradicted/final） | Plotly timeline |

### 最小可行版本（MVP）

只做 2 个文件：
1. `scripts/hypothesis_dashboard.py` — Streamlit app，从 SQLite 直接读取
2. 前 3 个视图（总览 + 转移 + lineage）

不引入新依赖（JSONL、parquet、Neo4j）。直接读已有 SQLite schema。
