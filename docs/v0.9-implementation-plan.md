## 后续可加入的 AI4AI 改进（不改变当前优先级）

这不是新的自动化科学决策系统，而是让后续工程改进更可控。

- **优化合同：** 每次优化前声明目标、允许修改范围、禁止修改范围、资源上限和人工升级条件。
- **两层经验：** 账本继续保存原始事实；单独的经验记录保存“为什么成功或失败”、适用条件和失效时间。
- **实际可见上下文收据：** 除原始资料外，记录模型真正收到的摘要、截断结果、prompt/template 版本和 context manifest。
- **人工升级出口：** 对高风险、证据冲突、跨版本资料缺失等情形输出 `ESCALATE`，由人决定。

这些能力只能优化提示、工具、上下文和工程 harness；不得让 agent 自行改变 schema、topology、gate、迁移规则或科学结论。
