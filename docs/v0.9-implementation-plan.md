## 已修复缺陷（供参考）

**CLI check-deps NameError（FIXED 2026-07-30）：** `REQUIRED_DEPENDENCIES` 所有权移入 `common.py`，删除 `engine.py` 猴补丁，新增 `tests/test_cli_standalone_imports.py`（5 passed）。

**Deep-research 宿主一致性（FIXED 2026-07-30）：** `detect_host_backend()`、`host_matches()`、`default_runtime_config()` 按宿主派生 backend；`cmd_deep_research_run` 加宿主门（不一致 exit 3，`--allow-host-mismatch` 放行）。Codex env 标记未验证，Codex 会话须显式 `--backend codex`。

**文献候选逐条过滤（FIXED）：** `_filter_unidentifiable_papers()`（`deep_research.py:333`）对每条论文独立检查 DOI/PMID/稳定 URL，缺失记录进入 `rejected_papers` 审计列表并写入 run artifact（`persist_run:421`、`:479`），全部不合格时 `DeepResearchError` fail-closed。测试见 `tests/test_deep_research.py:110`。

**runner 默认 Codex（FIXED 2026-07-31）：** `run_loop.py` 的 `DEFAULT_CONFIG` 不再写死 `backend: codex`；`ensure_pre_research()` 在 runner 未显式 override 时不传 `--backend`，由 `deep-research-run` 落回项目 `00_Preflight/deep_research_runtime.json`。

**mixed runtime spec（FIXED 2026-07-31）：** 新增 `validate_spec_consistency()`，拒绝 backend 与 executable/skill_path/plugin_dir 矛盾的 spec，接在 `cmd_deep_research_run` 的宿主门之后。
